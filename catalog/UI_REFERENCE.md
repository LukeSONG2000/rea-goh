## 构建顺序（Unity uGUI，全部复用已提取资产）
1. **P3 roster 网格**（数据/资产最齐，先出可见成果）→ 2. **P4 详情页**（技能列表+relic 板+标签）→ 3. **P5 战斗 HUD 对齐**（键位字母+buff 槽+计时器）→ 4. **P2 主城壳**（热键导航+资源栏，cantina 场景做背景）→ 5. P6 舰队（需先逆向舰队战斗，最后）

## 泛化指令（2026-10-16 用户设定，约束所有 UI 构建）
参考截图 P1-P6 只是**核心页种子**，不是验收终点。方法论（NGUI 序列化布局 → 原版数值 → 重建）必须**泛化到游戏全部屏幕**：
- 原料已规模化：catalog/ngui_layouts.json = 1099 个 UI bundle / 167,099 对象 / 154,882 NGUI 组件的**原版序列化布局**（含每屏 GameObject 树/锚点/精灵名/文本/层级）
- 泛化架构：构建**数据驱动的 NGUI→uGUI 渲染器**——通用组件实例化器按序列化布局自动生成任何屏幕（_widget=UISprite→Image+atlas 切片, UILabel→Text+loc 表, UIButton→交互），而非逐屏手工搭建
- 屏幕清单：从 bundle 名+内容提示枚举全部屏幕（数百个 ui_*_view），按"已复现核心页→同族扩展→其余"分级推进
- 交互逻辑：逐屏从 il2cpp dump 对应 View 类反编译接线（类名与 bundle 名一致，可直接定位）
