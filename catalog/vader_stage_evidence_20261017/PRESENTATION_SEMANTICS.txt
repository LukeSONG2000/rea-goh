3. CatmullRom original numerical construction
FinalizePath 1824A9BE0:
For open paths controlPoints[0].a = wps[1];
controlPoints[1].a = 2*wps[last] - wps[last-1].
For closed paths first = wps[len-2], last = wps[1].
This asymmetric OPEN start control differs from extrapolating both ends.
subdivisions = wps.Length * subdivisionsXSegment (DOPath supplies 10).
GetPoint 1824A9F00: segment=min(floor(perc*(len-1)),len-2),
t=perc*(len-1)-segment; a=previous wp or first control,
b=wps[segment], c=wps[segment+1], d=next wp or last control.
point=.5*(2*b + (-a+c)*t + (2*a-5*b+4*c-d)*t*t
             + (-a+3*b-3*c+d)*t*t*t).
Binary constants independently read from original DLL PE section offsets:
18529F0F0=3, 18529F198=5, 18529F170=4, 18529EE14=.5, 18529EF3C=1.
SetTimeToLengthTables 1824AA360: sample i=1..subdivisions at i/subdivisions;
length table is cumulative Euclidean distance from GetPoint(0),
time table contains corresponding i/subdivisions.
ConvertToConstantPathPerc 1824AB4B0:
linear path type returns input unchanged. For 0<perc<1 and positive total length,
desiredLength=perc*totalLength; find first cumulative length > desiredLength;
interpolate between previous/current time by interval distance fraction
(previous length/time zero for first interval). Clamp output to [0,1].
For nonpositive total length returns input; do not replace by arbitrary path speed.

using Approximately. CatmullRom getter180C05600 bytes b801000000c3 => minimum1.
Thus a single supplied destination always gets current position prepended;
two or more supplied points already starting at current position are not duplicated.
